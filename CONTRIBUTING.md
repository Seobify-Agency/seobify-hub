# Contributing

Thank you for your interest in Seobify Hub.

- **Issues are welcome.** Bug reports, unclear behaviour and feature ideas help us most. Include the tool, its version, your operating system and steps to reproduce.
- **Pull requests are not accepted at the moment.** We keep the code under a single owner for now so that licensing and maintenance stay simple. Pull requests will be closed without review; please open an issue instead.
- **Forks are fine.** The code is licensed under AGPL-3.0, so you may fork and modify it under the same license. If you distribute a modified version, remove the Seobify name, logos and report stamp as described in [TRADEMARKS.md](TRADEMARKS.md).
- **Security problems:** see [SECURITY.md](SECURITY.md).

---

**Türkçe:** Hata bildirimleri ve öneriler için issue açabilirsiniz. Şimdilik kod katkısı (pull request) kabul etmiyoruz; gelen pull request'ler incelenmeden kapatılır. AGPL-3.0 kapsamında kodu çatallayıp (fork) değiştirebilirsiniz; değiştirilmiş sürümü dağıtırsanız Seobify adını, logolarını ve rapor mührünü kaldırmanız gerekir.
